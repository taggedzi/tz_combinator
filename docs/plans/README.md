# Active implementation plans

Files in this directory describe approved or proposed work that has not yet
fully landed. They are engineering plans, not documentation of the currently
released interface. Current code, generated help, manuals, and policy documents
remain authoritative for present behavior.

When a plan is completed or superseded, move it to
[`docs/archive/plans`](../archive/plans/) and add the appropriate status note so
unchecked historical tasks are not mistaken for active assignments.
